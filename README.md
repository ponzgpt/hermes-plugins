# hermes-plugins

Landing pages for my [Hermes Agent](https://hermes-agent.nousresearch.com) plugins.

| Plugin | Landing | Repo |
|---|---|---|
| ☤ Psychopomp | https://psychopomp.technoir.cloud | [ponzgpt/psychopomp](https://github.com/ponzgpt/psychopomp) |
| 🕯 Sabbath | https://sabbath.technoir.cloud | [ponzgpt/sabbath](https://github.com/ponzgpt/sabbath) |

Each page is one hand-written HTML file served by nginx. `./scripts/check.sh` checks them and `./scripts/deploy.sh <plugin>` ships one. Not affiliated with Nous Research.
